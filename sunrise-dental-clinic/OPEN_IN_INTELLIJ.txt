OPEN THIS FOLDER IN INTELLIJ
============================

1. Unzip sunrise-dental-clinic.zip. You should get a folder named sunrise-dental-clinic.
2. In IntelliJ IDEA: File → Open → select that sunrise-dental-clinic folder (the one that contains pom.xml).
3. Trust the project. Wait for Maven to import (bottom-right).
4. File → Project Structure → Project → SDK 17 (or newer). Apply.
5. Import the database: XAMPP phpMyAdmin → Import → database/sunrise_dental.sql
   (Start MySQL in XAMPP first.)

HOW TO RUN (fixes "file in the editor is not runnable")
-------------------------------------------------------
Do NOT click Run on index.html, pom.xml, or a servlet.

Open this file:
  src/main/java/com/sunrisedental/SunriseDentalApp.java

Click the green triangle next to:
  public static void main(String[] args)

Or use the run configuration:  Run Sunrise Dental Clinic

Then open: http://localhost:8080/
Login: admin / Admin@123    or    staff / Staff@123
Stop: click the red square in IntelliJ.

Java packages (already created with files inside):
  com.sunrisedental            ← RUN SunriseDentalApp here
  com.sunrisedental.model
  com.sunrisedental.dao
  com.sunrisedental.servlet
  com.sunrisedental.filter
  com.sunrisedental.util
